# VideoCraft Agent Guidelines

## Context Workflow

- This is a small project. Prefer direct reads of `README.md`, `docs/`, `backend/`, and `frontend/` for implementation tasks.
- Use Repomix for resume writing, project summaries, interview material, and architecture snapshots.
- CodeGraph is optional here. Use it only when the project grows enough that call-chain or impact queries are faster than direct file reads.

## Resume Evidence

- Emphasize the implemented business loop: user brief and assets -> Dify workflow -> FastAPI validation/orchestration -> FFmpeg rendering -> frontend preview/download.
- Keep claims grounded in repository files. Do not claim production traffic, commercial deployment, or model training unless the code or docs prove it.
